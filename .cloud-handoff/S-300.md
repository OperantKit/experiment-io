## 引き継ぎ

- **user 承認待ち: 案 (a)** — session に渡す反応の時刻は `drive` が受信時にホストの `clock()` で付け、機器の時刻は `ResponseSample`（metadata または改名した field）に記録用として残す。正典の向きが「反応の時刻は機器が正」から「session の時刻はホストが正、機器の時刻は記録」に変わるので承認対象。OKL は `timestamp` 列をセッション時刻のままにし、response 行に optional 列 `device_time?` を足す（experiment-core / session-recorder / session-runner の後続変更）。取り込み側で TODO を `blocked` にする。
- 承認後の S-301 の範囲は `clock-domain.md` §5。要点: (1) `drive` の受信時刻付け + xfail 解除、(2) 実時計で強化子アクセス中も poll し `end_reinforcement` の前に drain、(3) 同じ poll の残りサンプルを捨てない（別 ID でもよい）、(4) docstring・README・README.ja の注記。案 (b) の同期命令と contingency-py の `_check_time` の緩和は含めない。
- S-215 の線形式仕様に「`time` は機器の時刻（記録用）、session の時刻はホストが受信時に付ける」の一文を入れる（§4.4）。
